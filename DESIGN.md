Мы это **не копируем как библиотеку компонентов**: каждый из этих репо сам говорит, что стиль подбирается под задачу. Ниже — решение под наше приложение.

## Прочтение задачи

Десктоп-приложение для одного человека, открывается каждый день. Язык — **«спортивный прибор»**: телеметрия болида, табло секундомера, хронофотография Марея. Никаких фиолетовых свечений, стекла и карточек «иконка + заголовок + текст» по три в ряд.

Ручки: **вариативность 6 · движение 6 · плотность 4.** Главное движение — сам персонаж, интерфейс вокруг спокойный.

## Фирменный приём: хронофотография

Каждое упражнение показывает линейный персонаж (кости + суставы), рядом **тающие следы** предыдущих поз и **траектории** ключевых суставов (кисть, колено, таз) — как на фотографиях Этьена-Жюля Марея 1880-х. Видно не только позу, но и путь движения. Рисуется в Remotion (`src/anim/**`), в приложении — `@remotion/player`.

## Цвет (один акцент, без чистого чёрного)

| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#0D0E0D` | фон окна |
| `--surface` | `#151715` | панели |
| `--surface-2` | `#1C1F1C` | приподнятые панели, поля ввода |
| `--line` | `#2A2E2A` | волосяные линии, рамки 1px |
| `--text` | `#ECEEE8` | основной текст |
| `--text-2` | `#9CA197` | вторичный |
| `--text-3` | `#62675F` | подписи, неактивное |
| `--accent` | `#FF5B2E` | **сигнальный**: главное действие, активный день, текущий подход, следы персонажа |
| `--accent-ink` | `#170803` | текст на акценте |
| `--accent-soft` | `rgba(255, 91, 46, .14)` | заливки под акцентом |

Акцент один на всё приложение, включая калории и виджет. Зелёный «успех», синие бейджи и т. п. не вводим: выполнено = акцент, не выполнено = `--text-3`.

## Шрифты (все локальные, через @fontsource, работают без интернета)

- **Unbounded** (кириллица, широкий) — только крупные заголовки экранов и название дня. Вес 500–700, трекинг −0.02em.
- **Geist** — весь интерфейс. 14–16 px текст, 12 px подписи.
- **Geist Mono** — табличные числа (ккал, граммы, даты), `font-variant-numeric: tabular-nums`.
- **Doto** (точечная матрица, только латиница/цифры) — живые счётчики: таймер, повторы, серия дней. Это табло.

Нельзя: Inter, Fraunces, Instrument Serif, засечки вообще.

## Форма

- Скругления: панели **12px**, поля 8px, кнопки и чипы — **полная пилюля**. Больше 16px на панели нельзя.
- Рамка **или** тень, не обе. По умолчанию — рамка `1px var(--line)`, без теней.
- Сетка 4px. Отступы панелей 20–24px.
- Иконки — только `@phosphor-icons/react`, weight `regular`/`bold`, своих SVG-иконок не рисуем.

## Движение

- Кривые: `--ease-out: cubic-bezier(.23,1,.32,1)`, `--ease-io: cubic-bezier(.77,0,.175,1)`.
- UI ≤ 250 мс. Нажатие: `scale(.97)` на `:active`, 100 мс.
- Переходы между вкладками: сдвиг 8px + прозрачность, 220 мс, без «прыжков».
- Пружины (`motion/react`, `{ type: 'spring', duration: .5, bounce: .15 }`) — для счётчиков, кольца таймера, отметки дня.
- Праздник (закрыл тренировку / серия) — единственное место для «вау»: табло Doto перещёлкивает цифры, следы персонажа вспыхивают акцентом.
- Всё уважает `prefers-reduced-motion`.

## Текст

- Русский, коротко, без «Добро пожаловать!», без восклицаний через строку, без эмодзи.
- Тире в интерфейсе — только короткое «–» или вообще перестроить фразу.
- Числа живые: «18 повторов», «4 мин 30 с», а не «N повторений».

## Компоненты (`src/ui/**`, пишет Claude, остальные используют)

`Button` (primary / ghost / icon), `Chip`, `Panel`, `Stat` (подпись + число Doto/Mono), `Segmented`, `NumberField`, `ProgressRing`, `Dots` (недельная лента дней).
Подключение: `import { Button, Panel } from '../ui'`. Токены — CSS-переменные из `src/styles/tokens.css`, подключены глобально.
